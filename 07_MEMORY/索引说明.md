# 记忆权威与检索
长期事实：canon＋逐章原文＋各章新增events/facts。
当前状态：最新正式memory的world/characters/items/threads/relationships/reader_knowledge；未有章时为initial。
规划：03_PLOT和05_VOLUMES，只是未来安排，不能污染已发生事实。
search.sqlite只收录规则/规划、初始状态、各章原文、各章新增事件事实、最新实体状态。它不反复索引每个旧快照；每次查询检测来源指纹，过期自动重建。
查询返回source、片段、总命中数和next_offset。片段只是导航，要读来源原文；没有命中不能证明不存在。索引可删重建，不能修改索引当作改事实。
